Download the hub

  • Tap Download at the top. On iPhone use Safari, tap Share, then “Add to Home Screen”.
  • After that every app opens from the hub, even with no internet.

Go back to the hub

  • Use your phone's back button, or tap the small “Hub” tab at the top of the screen.

Install a mod

  • Open the Mods tab, pick NauticX or Nautic Online, and tap Install.
  • NauticX: mods are on right away. Turn them on or off with the Mods button in NauticX.
  • Nautic Online: pick the mods when you make a server.

Make a mod

  • Tap “Make a mod”, give it a name and write the code. Tap a line under the code box to add it.
  • Easy: #gravity = 0.5 on its own is a whole mod.
  • Bigger mods: #every = 10s … #end, #if = {score} > 3, #set = score = 0, and events like #on_jump.
  • The checker under the code tells you about mistakes before you save.

Servers in Nautic Online

  • Open Nautic Online and tap Servers. Public servers show in the list for everyone. Link only servers need the link. Private servers need the link and the password.
  • When everyone leaves, the server pauses. It carries on from the same spot when someone joins.
