# UltraNautic Hub

Free apps and games, no paywalls. Download the hub and every app inside it plays, even offline.

Open it: https://asadalsyed29-create.github.io/Ultranautic-hub/

- `index.html`, `manifest.webmanifest`, `sw.js`, `icons/`: the hub (the one app you download)
- `nautic/`: Nautic Editor (video, drawing and photo editor). Edit `nautic/src/`, then run `sh nautic/build.sh`.
- `nauticx/`: NauticX (3D game maker)
- Nautic Online lives in its own repository (Funz-online).
